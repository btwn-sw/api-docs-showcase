# Technical Writing Portfolio

## What you'll get from this

This portfolio demonstrates bilingual (English/Korean) technical writing across four different kinds of work: writing API documentation end to end and building and documenting an original AI-powered tool from scratch.

<br>

## Structure

```
technical-writing-portfolio/
├── developer-portal/
│   └── eventbrite-api/
│       ├── docs/en/
│       │   ├── api/            (api-reference, error-reference, quick-reference)
│       │   ├── examples/       (code-examples)
│       │   ├── get-started/    (quick-start)
│       │   ├── guides/         (authentication, pagination, response_handling, troubleshooting)
│       │   ├── reference/      (glossary)
│       │   ├── testing/        (api-test-results)
│       │   └── tutorials/      (first-api-call)
│       └── docs/ko/
└── hidoc/
    ├── architecture/
    └── how-it-works/

```

<br>

## Language

Every project is written in both English and Korean. English pages live under an `en` path in each folder; Korean pages live under the matching `ko` path, with a language-switch link at the top of every page.
